Meta Tags Explained: Title and Description That Rank

Meta tags are the snippets of code that tell search engines — and searchers — what a page is about. Two of them run your presence in the results: the title tag, which becomes the clickable headline, and the meta description, the short text beneath it. Get these meta tags right and the same ranking produces more clicks; get them wrong and you are invisible in plain sight.

The title tag: your headline in search

The title tag is the strongest on-page signal of what a page covers and the first thing a searcher reads. Good titles put the page's main topic at the front, match what the page genuinely delivers, and read like headlines a human would click. Aim for roughly 50–60 characters so the full title usually displays, and give every page a unique one — duplicated titles across a site confuse both search engines and visitors. The meta description: your free advert

The meta description does not directly raise rankings — Google says so openly — but it decides whether the searcher clicks you or the result above you. Write it as an advert: what the page offers, who it helps, and one concrete detail or benefit, in about 150–160 characters. Include the phrase a searcher would use, naturally, once. If you skip it, Google will improvise a snippet from your page text, and it is rarely flattering.

Other meta tags worth knowing

  • Viewport tag — essential: it makes pages display correctly on phones. Without it, mobile visitors get a shrunken desktop page.
  • Robots tag — optional instructions like “noindex” for pages you deliberately keep out of search (thank-you pages, account screens).
  • Open Graph tags — control the title, description and image shown when your page is shared on social media. Test them with an OG preview tool.
  • Canonical tag — tells search engines which version of a duplicated page is the main one.

Meta tag mistakes that waste good pages

  • The same title on every page (“Home”, or the site name repeated).
  • Keyword stuffing: “Cheap Shoes, Best Cheap Shoes, Buy Cheap Shoes Online” — unreadable and counterproductive.
  • Descriptions that promise what the page does not deliver — clicks that bounce straight back teach Google the page disappoints.
  • Leaving descriptions empty on your most important pages.

Key takeaways

  • Title tag: unique, topic first, about 50–60 characters.
  • Meta description: an honest advert of about 150–160 characters that earns the click.
  • Every page gets its own pair — duplicates waste rankings you already have.

Frequently asked questions

Do meta keywords still matter?

No. Google ignores the meta keywords tag entirely, and has for many years. Spend the effort on titles and descriptions instead.

Why did Google rewrite my title or description?

Google rewrites snippets it thinks match a specific search better. Clear, accurate, page-specific titles and descriptions are rewritten least often.

How long should a meta description be?

Around 150–160 characters on desktop; mobile shows less. Put the most persuasive words early.

Should every page have meta tags?

Every page you want found in search, yes. Pages deliberately kept out of search can use a noindex robots tag instead.
