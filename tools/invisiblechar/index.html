About the Invisible Character

An invisible character is a real character that takes up space but shows nothing on screen — used for blank names in games and social apps, empty-looking messages, spacing tricks and testing how apps handle hidden input. This tool lets you copy three reliable invisible characters and test exactly what you pasted.

How to use the Invisible Character — step by step

  1. Choose your character: Zero-Width Space (U+200B), Hangul Filler (U+3164) or Braille Blank (U+2800).
  2. Tap its Copy button.
  3. Paste it where you need it — a name field, message or bio.
  4. Use the test box to confirm the paste worked: it counts the hidden characters for you.

Worked example

Copy the Hangul Filler and paste it as your display name: the field accepts it because it contains a real character, yet the name appears completely blank. The test box shows '1 character' even though nothing is visible.

When to use it

Use it for blank social-media names, sending an empty-looking message, adding invisible spacing in bios, or testing forms and apps you are building.

Common mistakes to avoid

  • Assuming every app accepts every character — some platforms strip zero-width characters; if one fails, try the Braille Blank instead.
  • Pasting invisible characters into passwords or codes, where they cause silent, confusing failures.
  • Forgetting they are there — invisible characters in copied text can break searches and usernames later.

Invisible Character — frequently asked questions

Which invisible character is best?

Hangul Filler (U+3164) survives in most name fields, Braille Blank (U+2800) is the most visible-width option, and Zero-Width Space (U+200B) adds no width at all.

Is an invisible character the same as a space?

No. A normal space is U+0020 and many fields trim it. Invisible characters are different code points that most trimming rules leave alone.
