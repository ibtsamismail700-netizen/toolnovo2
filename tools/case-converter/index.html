About the Case Converter

The case converter rewrites text in every standard letter case with one click: UPPERCASE, lowercase, Title Case, Sentence case, camelCase, PascalCase, snake_case, kebab-case and alternating case. Developers, writers and social media managers use these formats daily — URLs, code, headlines and hashtags all have their own rules.

How to use the Case Converter — step by step

  1. Type or paste your text.
  2. Click the case you need — the result appears below.
  3. Copy the result with the Copy button.

Worked example

The phrase 'the quick brown fox' becomes THE QUICK BROWN FOX in uppercase, The Quick Brown Fox in Title Case, theQuickBrownFox in camelCase, and the-quick-brown-fox in kebab-case — the last one is exactly how it should appear in a web address.

When to use it

Use it for headlines, code variables, file names, URL slugs, database fields, and fixing text typed with Caps Lock on by accident.

Common mistakes to avoid

  • Using Title Case rules for sentences — headlines and sentences follow different capitalisation.
  • Putting spaces or capitals in URLs — use kebab-case lowercase for web addresses.
  • Assuming camelCase and PascalCase are the same: PascalCase capitalises the first word too.

Which case where: titles, code and constants

The case styles exist because different readers — humans, compilers, style guides — expect different signals. Title Case itself splits into styles: AP style (news) lowercases short prepositions like 'of' and 'in', while Chicago style is more generous with capitals, so the same headline can legitimately look different in two publications. Sentence case — only the first word and proper nouns capitalised — is the modern default for app buttons, form labels and documentation because it reads fastest. In code, the conventions are near-universal: camelCase for JavaScript variables and functions, PascalCase for classes and components, snake_case for Python and SQL, and CONSTANT_CASE (upper snake) for values that never change, like MAX_RETRIES = 5. Matching the convention of the language you are writing in matters more than personal taste — reviewers and linters enforce it.

Case Converter — frequently asked questions

What case do URLs use?

Lowercase kebab-case: words separated by hyphens, no capitals or spaces.

What is the difference between snake_case and kebab-case?

Underscores versus hyphens. Python and databases favour snake_case; URLs and CSS favour kebab-case.

What case do constants use in code?

CONSTANT_CASE — all capitals with underscores, such as TAX_RATE or MAX_FILE_SIZE. It signals 'this value is fixed' in almost every programming language.
