About the XML Sitemap Generator

The XML sitemap generator converts a plain list of URLs into a standards-compliant sitemap.xml, complete with last-modified dates, change frequency and priority, ready to upload and submit to Google Search Console and Bing Webmaster Tools.

How to use the XML Sitemap Generator — step by step

  1. Paste your page URLs, one per line, as full https addresses.
  2. Choose a change frequency and priority that honestly reflect the pages.
  3. Copy the generated XML and save it as sitemap.xml.
  4. Upload it to your domain root and submit its URL in Search Console.

Worked example

Three URLs — a homepage, about page and contact page — become a valid urlset document in seconds, each stamped with today's date, weekly change frequency and 0.8 priority.

When to use it

Use it for small and medium sites without a CMS generating one automatically, after adding pages, or to rebuild a broken sitemap.

Common mistakes to avoid

  • Including redirected, non-200 or noindex URLs — a sitemap should list only final, indexable pages.
  • Listing http and https or www and non-www versions of the same page.
  • Setting every page to priority 1.0 and daily changes — engines ignore signals that are clearly inflated.

XML Sitemap Generator — frequently asked questions

How big can a sitemap be?

50,000 URLs or 50 MB uncompressed per file. Larger sites use a sitemap index of multiple files.

Does a sitemap guarantee indexing?

No — it helps discovery. Indexing still depends on quality, links and crawl budget.
